## 1. 需求背景

当前系统是通用商机管理系统，字段较少，偏销售漏斗管理。Excel 中的“商机池”体现了设备事业群真实业务字段，要求系统能够承载设备类商机的提报、授权、报备、投标、交付、中标、人员归属和定期更新。

本次 Excel 副本只包含 `商机池` 一张表，共 38 列、约 1900 行历史数据。不包含 SI 认证表和省区人员表，因此本次需求范围只覆盖设备事业群商机池。

## 2. 新增业务规则

从 Excel 字段和样例推断，新增规则如下：

1. 提报日期由系统自动生成，无需人工填写。
2. 商机信息尽可能填全，尤其包括提报人所属部门、提报人省区、供货省区、销售部门。
3. 项目名称必须写清楚，建议格式为“地区 + 用户名称 + 具体采购产品”。
4. 每周需要更新项目阶段、赢率，并用文字描述本周项目进展。当前 Excel 没有明确“本周进展”列，建议系统用跟进日志或新增 `weeklyProgress` 字段承载。
5. 赢率使用业务枚举，而不是任意数字：`10%-没有把握`、`30%-把握很小`、`50%-可以参与`、`70%-赢面很大`、`100%-肯定中标`。
6. 是否可以提前写参数、是否需要唯一授权、是否中标、是否报备成功属于布尔/枚举字段。
7. 采购形式使用枚举：`一次性采购（一次性交付）`、`带量采购（分批交付）`、`框采入围`、`电商平台线上采购`。
8. 需求设备类型支持多选，样例包括：`数码打印A4`、`数码打印A3`、`办公设备`、`办公纸品`、`打印耗材`。
9. 授权品类支持多选，样例包括：`A3复印机`、`A4激光打印机`、`A4激光多功能一体机`、`A4喷墨多功能一体机`、`耗材`、`配件`。
10. 提醒编辑时间和最后编辑时间用于定期维护提醒，应与系统提醒/待办联动。
11. 手机端商机看板和列表必须基于企业微信 `wecomUserId` 做后端数据隔离，不能只依赖姓名、前端筛选或 `owner` 文本字段。
12. 领导或授权用户通过用户白名单查看和编辑指定人员商机，管理员查看和编辑全部商机。
13. 历史 Excel 导入数据若无法匹配企业微信用户，第一期标记为未归属，仅管理员可见。

## 5. 是否影响历史业务

有影响，但可兼容。

影响点：

1. 金额单位冲突：当前系统前端表单写“元”，Excel 字段是“万元”，样例中还存在部分看似元的值。必须明确最终单位。
2. 赢率冲突：当前系统是 `0-100` 数字，Excel 是带业务描述的枚举。
3. 阶段冲突：当前系统阶段是 CRM 漏斗，Excel 强调“项目阶段”，但 Excel 副本未提供项目阶段字段，可能依赖外部或遗漏。
4. 日期冲突：当前系统只有预计结单日期，Excel 有提报日期、预计交付、投标截止、提醒编辑、最后编辑。
5. 负责人冲突：当前只有 owner，Excel 有提报人、销售、市场部经理、省总、A4/A3 经理。

兼容方案：

- 保留当前字段，不删除。
- 新增设备事业群字段。
- `value` 保持当前展示兼容，同时新增 `estimatedPurchaseAmountWan` 作为业务字段。
- `probability` 保持数值，同时新增 `winRateLabel` 保存 Excel 枚举。
- `owner` 默认映射为销售，历史数据继续可展示。

## 6. 是否与旧需求冲突

基于当前代码推断，存在以下冲突：

| 冲突点 | 旧逻辑 | 新需求 | 处理方案 |
---|---|---|---|
| 金额单位 | 元 | 万元 | 增加业务金额字段，前端明确单位 |
| 赢率 | 数字百分比 | 枚举标签 | 保存数值和标签两个字段 |
| 阶段 | CRM 阶段 | 每周更新项目阶段 | 保留 CRM 阶段，新增项目进展/业务状态 |
| 负责人 | 单 owner | 多角色人员 | owner 保留，新增多角色字段 |
| 日期 | closeDate | 多业务日期 | 拆分日期字段 |
| 来源 | source | Excel 无来源 | 保留旧字段，非必填 |
| 联系人 | 当前系统有联系人 | Excel 商机池无联系人 | 保留旧字段，非必填 |
| 权限身份 | 姓名/owner 文本 | 企业微信 `wecomUserId` | 新增用户表和商机归属字段，后端强制过滤 |
| 领导可见范围 | 无 | 用户白名单 | 新增白名单配置，仅管理员可维护 |
| 修改追溯 | 活动日志粗粒度 | 字段级修订记录 | 新增修订记录表，普通用户/领导/管理员按权限查看 |

没有发现必须删除旧功能的冲突。建议采用兼容式扩展。

## 7. 验收标准

1. 系统能保存 Excel 商机池 38 列中已命名的核心业务字段。
2. 新增/编辑商机时能录入设备类型、品类型号、数量、金额、授权、采购形式、投标/交付日期。
3. 列表可按行业、省区、供货省区、采购形式、赢率、中标状态筛选。
4. 详情页展示业务字段和每周进展。
5. 仪表盘支持按行业、设备类型、供货省区、采购形式统计。
6. 历史旧商机不丢失、不因新增字段为空而报错。
7. API 兼容旧字段，同时返回新字段。
8. 手机端 `我的商机`、列表和看板均由后端按企业微信身份返回可见数据。
9. 用户板块可维护用户角色、启用状态和白名单。
10. 领导可查看、编辑白名单人员商机，且所有字段修改可追溯。
11. 未归属历史数据仅管理员可见。
