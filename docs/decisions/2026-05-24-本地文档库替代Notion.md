# 决策记录：使用本地 docs 替代 Notion

日期：2026-05-24

## 背景

用户当前使用 API key 登录 Codex 桌面应用，不能使用 Plugins 功能连接 Notion。虽然已安装 Notion Knowledge Capture Skill，但 Skill 只是工作流说明，不等于 Notion 授权连接。

## 决策

使用项目本地 `docs` 目录作为需求知识库，替代 Notion。

## 目录规范

- `docs/product/`：产品总览和模块说明
- `docs/requirements/`：PRD、需求分析、字段分析
- `docs/design/`：系统设计、接口设计、数据库设计、SQL 草案
- `docs/decisions/`：关键决策
- `docs/changelog/`：需求变更记录

## 后续协作规则

每次新需求处理前，必须先检索 `docs` 下的历史需求和设计，确认：

- 是否字段重复
- 是否业务规则冲突
- 是否接口兼容
- 是否数据库字段已有定义
- 是否影响历史数据
- 是否影响前端列表、看板、详情、仪表盘

## 后果

优点：

- 不依赖外部 Notion 连接。
- 文档与代码同仓库，便于版本管理。
- Codex 可直接检索和更新。

限制：

- 不能直接同步 Notion。
- 多人协同时需要通过 Git 或文件共享保持一致。
