# 商机管理系统 (BOMS) 飞书全套路集成与原生化改造方案

经过对 BOMS 核心业务需求（商机提报、查重、数据隔离、OA 流程联动、每日定时提醒）的梳理，**完全可以将整个应用彻底“搬到飞书上”**，使之成为一个飞书原生的企业数字化应用。

以下是具体的集成与改造架构方案：

---

## 1. 飞书原生化改造核心方案

我们可以通过以下四个维度，将目前“Web网页 + 企微提醒 + 外部OA”的架构，改造为**“飞书一体化智能工作台”**：

### 1.1 免登与工作台集成 (SSO & Workbench)
* **方案**：在飞书开放平台创建“BOMS 企业自建应用”，开启“网页”功能，将现有的自适应 Vue 前端页面嵌入飞书工作台。
* **效果**：销售在手机或 PC 飞书工作台点击 BOMS 图标，系统通过飞书 OAuth2 流程进行**免密登录（免登）**。
* **多账号绑定**：在数据库用户表（`SystemUser`）中增加 `feishu_union_id` 和 `feishu_open_id`。通过销售的【手机号】自动关联其企微账号与飞书账号，实现双平台平滑过渡。

### 1.2 企微消息替换为“飞书智能卡片” (Feishu Message Cards)
* **方案**：使用飞书机器人（Bot）接口，将原本的企微消息推送重构为**飞书互动消息卡片**。
* **效果**：每日早上 9:00 扫描触发的 7 大提醒场景，将以排版美观的卡片形式直发销售的飞书聊天会话。
* **交互性**：卡片上可直接放置快捷按钮（如 `[去更新进展]`、`[补齐授权材料]`）。销售点击按钮会直接在飞书内部拉起 BOMS 微应用，缩短操作链路。

### 1.3 外部 OA 替换为“飞书审批” (Feishu Approvals)
* **方案**：不再对接外部繁杂的 OA 系统，直接对接**飞书审批**。
  1. **发起审批**：销售在 BOMS 提报页面填完核心数据后，点击“发起报备”，BOMS 后端调用飞书审批接口（`/open-apis/approval/v4/instances`）自动创建审批单，并拉起飞书审批界面。
  2. **状态联动**：BOMS 注册飞书审批的事件回调（Webhook）。当审批单流转、驳回、归档或流转到特定节点（如 06 授权节点）时，飞书审批系统会实时回调 BOMS 后端，触发商机的 `SOFT_LOCKED`（临时冻结）和 `HARD_LOCKED`（硬锁定）状态。

### 1.4 数据协同：商机表单同步至“飞书多维表格” (Lark Base)
* **方案**：在飞书多维表格中建表，BOMS 数据库发生商机增删改时，通过飞书多维表格 API 实时双向同步。
* **效果**：对于管理层和数据分析人员，可以直接在飞书多维表格中查看商机，利用飞书多维表格强大的仪表盘、甘特图和协同编辑功能进行数据分析，无需我们在 BOMS 前端开发复杂的图表。

## 3. 从业务方便角度（为什么推荐这样做？）

业务人员在外面跑业务时，最核心的诉求是**“快、顺、稳”**。如果完全搬到飞书上，体验将有质的提升：

| 体验维度 | 原有“WeCom + 网页 + 外部OA”模式 | 飞书一体化原生应用模式 |
| :--- | :--- | :--- |
| **登录与入口** | 销售需要从企微/浏览器输入密码，经常失效重登，十分挫败。 | **打开飞书即用**：从飞书应用列表直接点开，飞书底层自动静默登录，无需输入任何账号密码。 |
| **填单录入** | 几十个字段直接展示，手机端极难输入。 | **一键拍照识别+精简填单**：借助飞书 H5 轻松调用手机摄像头，通过 OCR 自动识别招标文件照片自动填表，首期仅需填 4 个字段即可提交。 |
| **流程流转** | 提报完商机，要跳出到别的 OA 系统里重新建单、手动录入数据。 | **一键直达飞书审批**：在提报完成页面，点击“发起报备”，自动生成飞书审批实例并在飞书弹窗，一站式闭环。 |
| **异常催办** | 每天看邮件或企微被动接收一段文字提醒。 | **强交互卡片**：收到飞书提醒卡片后，卡片上直接带有 `[立即更新进展]` 等交互按钮，销售一键即可进入对应的提报项，极为顺手。 |

## 4. 落地实施路线规划

如果您确认将整个应用原生化迁移至飞书，我们可以分步实施：

* **第一阶段 (打通登录与提醒)**：创建自建应用，实现飞书免登，并将每日 9:00 的企微提醒重构为飞书消息卡片直发。
* **第二阶段 (打通审批流)**：用飞书审批 API 替换现有的 Mock OA 接口，实现飞书审批的流转、锁状态回调（SOFT/HARD LOCK）。
* **第三阶段 (协同提效)**：对接飞书多维表格，自动生成商机数据大盘，供领导查看分析。
