# 飞书日历查询脚本说明

## 目标

在本地通过飞书开放平台接口查询日历和日程，便于临时查看个人或应用可访问的飞书日历。脚本不保存任何密钥，只从环境变量读取凭证。

脚本路径：

```powershell
node tools/feishu-calendar.mjs
```

## 凭证方式

查询“我的日历”建议使用用户访问凭证：

```powershell
$env:FEISHU_USER_ACCESS_TOKEN="你的 user_access_token"
```

如果只需要查询自建应用身份可访问的日历，也可以使用应用凭证自动换取 `tenant_access_token`：

```powershell
$env:FEISHU_APP_ID="cli_xxx"
$env:FEISHU_APP_SECRET="xxx"
```

如果已经有租户访问凭证，也可以直接设置：

```powershell
$env:FEISHU_TENANT_ACCESS_TOKEN="t-xxx"
```

注意：`tenant_access_token` 通常不能代表你本人读取个人主日历；查个人日历时应使用 `FEISHU_USER_ACCESS_TOKEN`，并确保飞书开放平台应用已开通日历读取相关权限。

## 常用命令

列出当前凭证可访问的日历：

```powershell
node tools/feishu-calendar.mjs calendars
```

查询未来 7 天主日历日程：

```powershell
node tools/feishu-calendar.mjs events
```

查询今天日程：

```powershell
node tools/feishu-calendar.mjs events --days 1
```

查询指定日期范围：

```powershell
node tools/feishu-calendar.mjs events --from 2026-05-29 --to 2026-05-30
```

查询指定日历：

```powershell
node tools/feishu-calendar.mjs events --calendar-id primary --days 1
```

查询所有可访问日历，并输出 JSON：

```powershell
node tools/feishu-calendar.mjs events --all-calendars --days 7 --json
```

## 环境变量

- `FEISHU_USER_ACCESS_TOKEN`：用户访问凭证，查询个人日历时优先使用。
- `FEISHU_TENANT_ACCESS_TOKEN`：租户访问凭证，适合应用身份查询。
- `FEISHU_APP_ID`：飞书自建应用 App ID。
- `FEISHU_APP_SECRET`：飞书自建应用 App Secret。
- `FEISHU_CALENDAR_ID`：默认日历 ID，可被命令行 `--calendar-id` 覆盖。
- `FEISHU_BASE_URL`：默认 `https://open.feishu.cn`；Lark 国际版可设为 `https://open.larksuite.com`。
- `FEISHU_TIMEZONE`：输出时间时区，默认 `Asia/Shanghai`。

## 权限提醒

飞书开放平台应用需要开启日历读取权限，并在管理后台发布或重新发布权限变更。若返回权限错误，先检查应用权限、用户授权范围和当前 token 类型。
